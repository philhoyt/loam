A block theme with an earthy palette and generous type.

== Description ==

Loam is a block theme for the Site Editor. It ships an eight-color palette, a fluid type scale, a seven-step spacing scale, header and footer template parts, and block patterns for the header, footer, posts list, comments, post navigation, search and 404 pages, plus a hero banner.

Colors, typography, spacing and layout widths are defined in theme.json, so the Styles panel edits them without custom CSS.
